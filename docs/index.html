Fluxo — um clique do jogador

flowchart TD
    A[Clique em .square] --> B{myTurn?}
    B -->|não| Z[Fim ou turno futuro]
    B -->|sim| C{moveable?}
    C -->|não| D[checkBlack calcula scopes]
    D --> E{scopes.length > 0?}
    E -->|sim| F[moveable=true, guarda moveTarget e moveScopes]
    E -->|não| G[Ignora ou peça sem movimento]
    C -->|sim| H{Casa em moveScopes?}
    H -->|não| I[Cancela seleção]
    H -->|sim| J[Copia values → checkArr]
    J --> K[Simula lance]
    K --> L[checkWhite: rei branco em xeque?]
    L -->|sim| M[alert Rei em perigo]
    L -->|não| N[Atualiza values, roque, promoção]
    N --> O[myTurn=false, setTimeout chooseTurn]
    F --> P[updateSquareColor + render peças]
    I --> P
    M --> P
    N --> P

Referência de funções

Função Onde Papel
window.onload js/script.js Monta tabuleiro, define values, registra cliques, chama updateSquareColor.
updateSquareColor() Interna ao onload Pinta casas claras/escuras (#fcce9c / #d58d45).
checkBlack() Global no script Calcula casas legais das peças brancas (encoding o,t,m,v,w,l). Deveria receber índice n como parâmetro.
checkWhite(n, values) Global no script Calcula ataques/movimentos das peças pretas (p,r,n,b,q,k) — usado na simulação de xeque.
check() Handler de clique Seleciona peça, valida destino, simula xeque, aplica lance, re-renderiza DOM.
chooseTurn() Global Placeholder após 1 s; turno das pretas / IA ainda não implementado.

Variáveis de estado (contrato do jogo)

Variável Tipo Significado
values[64] array Tabuleiro: letra da peça ou 0 vazio. Fonte da verdade.
sqs HTMLCollection Referência às 64 div.square (classe s0…s63).
moveable boolean True após selecionar peça com movimentos.
moveTarget number Índice da peça selecionada.
moveScopes string[] Índices de destino permitidos (como strings).
myTurn boolean True = vez das brancas (fluxo atual).
ck, cr1, cr2, cl boolean Direitos de roque e flag de roque curto em andamento.

Códigos das peças no array

Pretas (rank inferior no array)

  • p peão · n cavalo · b bispo
  • r torre · q dama · k rei

Brancas (encoding alternativo)

  • o peão · m cavalo · v bispo
  • t torre · w dama · l rei

Índice n: linha = Math.floor(n / 8), coluna = n % 8. Casa 0 = canto superior esquerdo do tabuleiro desenhado.
